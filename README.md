# CarSharing

CarSharing is a car rental web application built with React. The project provides a user interface for browsing available cars and selecting rental dates.

The application is currently being developed towards a complete car reservation system with backend services and a database.
## Live Demo

[View CarSharing application](https://www.kamilnowocien.pl/carsharing/)

## Features

- Browse available cars
- Car listing and presentation
- Rental date range selection
- Multi-page navigation
- Responsive user interface
- Reusable React components

## Tech Stack

- React
- JavaScript
- Material UI
- React Router
- react-date-range
- date-fns
- Sass

## Getting Started

Clone the repository:

```bash
git clone https://github.com/nowocienka/carsharing.git
cd carsharing
npm install
npm start
```
